# Issues

Espaço público para a comunidade do **I.U.N.A** reportar problemas e sugerir
melhorias para o modpack e o servidor.

<p align="center">
  <a href="https://github.com/IunaMC/issues/issues/new/choose"><b>Abrir uma issue</b></a>
</p>

## O que dá para abrir aqui

| Tipo | Quando usar |
| :-- | :-- |
| **Bug ou crash** | Algo não funciona como deveria, ou o jogo/servidor fechou sozinho. |
| **Sugestão de mod** | Adicionar, remover ou atualizar um mod do modpack. |
| **Issue em branco** | Qualquer outra ideia, dúvida ou melhoria. |

## Antes de abrir

- Procure nas [issues existentes](https://github.com/IunaMC/issues/issues?q=is%3Aissue) se alguém já reportou a mesma coisa.
- Confira o [changelog do modpack](https://github.com/IunaMC/modpack-cliente/blob/main/MUDANCAS.md): pode ser que já tenha sido resolvido.
- Use sempre a [última versão do modpack](https://github.com/IunaMC/modpack-cliente/releases/latest).
- Se o jogo fechou, anexe o crash report (`crash-reports/`) ou o `logs/latest.log`.

## Labels

| Label | Significado |
| :-- | :-- |
| `triagem` | Ainda não foi analisada |
| `bug` · `crash` | Problemas no jogo ou no servidor |
| `sugestão de mod` · `melhoria` | Ideias e pedidos |
| `cliente` · `servidor` | Onde o problema acontece |
| `dúvida` | Perguntas sobre o modpack ou o servidor |
| `duplicada` · `inválida` · `não será feito` | Issues encerradas sem mudança |
